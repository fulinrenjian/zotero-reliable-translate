# 划词翻译增强版（Reliable Translate）

本页保留实现与迁移细节。项目使用与署名以 [README.md](README.md) 为入口；分支维护者为 fulinrenjian，AI 辅助开发。0.1.4 在浮窗缩放与滚动修复的基础上新增移动手柄，对应源码和安装包见 [0.1.4 发布页](https://github.com/fulinrenjian/zotero-reliable-translate/releases/tag/v0.1.4)。各版本的实测范围详见 [验证说明](docs/VERIFICATION.md)。

这是基于 [Translate for Zotero v2.4.8](https://github.com/windingwind/zotero-pdf-translate/releases/tag/v2.4.8) 的开源定制版，保留上游翻译服务与配置界面，针对划词翻译的状态显示、重试和选区绑定作修改。它不是上游官方发行版。

## 插件身份与兼容性

- 名称：划词翻译增强版（Reliable Translate）
- 版本：0.1.4
- 插件 ID：`reliabletranslate@codex.local`
- 资源命名空间：`reliabletranslate`
- Zotero 全局实例：`ReliableTranslate`
- 设置分支：`extensions.zotero.ReliableTranslate.`
- 当前兼容范围：Zotero 10.0.x。实际运行验证结果以交付检查记录为准。
- Zotero 要求插件声明 HTTPS 更新地址。本版使用本地回环占位地址 `https://127.0.0.1:65535/reliabletranslate/updates.json` 来满足加载要求，不提供更新服务器，不使用远程域名或原插件的更新地址。
- 安装后仅关闭本插件的后台更新；更新需手动安装新的定制版 XPI。手动点击「检查更新」可能提示连接失败或更新检查失败，这是占位地址没有更新服务器的预期表现。

## 使用与旧版切换

安装后，插件只在本机把旧版 `extensions.zotero.ZoteroPDFTranslate.` 分支中由用户设置的值复制到新分支。已有新分支用户设置不会被覆盖，旧分支不会被改动或删除。服务凭证随配置在本机复制，不进入源码、XPI、日志或导出文件；后续翻译仍使用用户选择的服务。

迁移只进行一次，完成标记为 `reliableSetup.migratedFrom248`。如果途中失败，不记录完成标记，下次启动会补齐尚未写入的值。一次迁移后再修改旧插件设置，不会自动同步到新版。

如果旧版 Translate for Zotero 仍处于启用状态，新版会显示提示并暂停注册翻译入口，避免两套划词监听和快捷键同时触发。请在 Zotero「工具 → 插件」中停用旧版，再重新启用本插件或重启 Zotero。插件不会自行更改旧版的启用状态。

浮窗应分别显示原文和翻译状态，并提供手动翻译／重试入口。服务端断连、限流或要求人工验证时应显示相应错误；本插件不能保证第三方服务始终可用，也不会绕过其验证。

## 0.1.4 移动翻译框

按住浮窗顶部的「⠿ 移动」并拖动，可把翻译框移开，查看下方图片。移动保持现有宽高，范围限制在当前阅读器可见区域。译文刷新或切换原文/译文时保留当前浮窗位置；重新选择另一段文字时，浮窗由原生阅读器放在新选区附近。

本机从 0.1.3 升级并正常重启后，已在单词选区中实测顶部手柄移动、右边界限制及原文/译文切换后位置保持。移动过程中浮窗维持 420 × 317 尺寸，底下 PDF 未滚动，八个缩放手柄和原生颜色按钮均保留。重新点击同一单词产生新浮窗时，恢复原生选区附近的位置。193 项离线测试、类型检查和构建通过。本轮未做完整图注或段落测速，也未重新实测笔记保存及物理触控板。

## 0.1.3 浮窗缩放与滚动

鼠标移到浮窗四边或四角后拖动，可以调整整体宽度和高度，译文区域随之伸缩。默认尺寸为 420 × 360 CSS 像素；启用设置中的「弹窗：记住大小」时，拖动结束后保存尺寸，并在重新打开浮窗时恢复。点击浮窗顶部的「↺」可恢复默认尺寸。可用范围受阅读器窗口约束；原生工具和提示行需要额外空间时，最小高度会相应增加。

译文区采用单一滚动区域，浮窗面板不再额外嵌套滚动条。滚轮在译文内使用原生滚动，在非按钮和非下拉框的浮窗空白区域也可滚动译文；到达边界后不将滚动传给底下的 PDF。状态刷新不会反复重设相同文本，流式返回也会尽量保持当前阅读位置和复制选区。

本机已实测四边、四角拖动、译文随尺寸变化、底部滚动隔离，以及重新打开时恢复尺寸。正常重启 Zotero 后也已验证：0.1.3 保持启用，浮窗恢复重启前保存的 661 × 461 尺寸。物理触控板未实测，细小滚动量和单位换算通过自动化检查。复制、切换翻译源和加入笔记入口保留；本轮未重新实测笔记写入，历史保存验证见 0.1.1 记录。

## 0.1.1 提速与加入笔记

2026-10-12 使用 107、132、199 词的公开合成英文段落，在 Zotero 内比较知网、必应和腾讯。两轮必应请求返回译文耗时为 0.275–0.671 秒；知网返回文本为 2.766–11.516 秒，其中一次混入大段原英文，完整性不足。因此 0.1.1 把原来的知网默认段落服务切换为必应，保留单词词典及其他配置。这个选择只应用一次；以后手动改选的服务不会被下一次启动覆盖。已有其他非默认服务保持原选择。测速是该次会话的数据，实际浮窗显示时间和网络波动见公开验证说明。

必应和腾讯的网络请求设定了 8 秒失败上限，并关闭隐藏的服务端错误重试；这不表示成功翻译要等待 8 秒。再次选择已经成功的同一段落仍会复用结果，手动重试会发起新的请求。知网保留其默认分片间隔，新增匿名令牌请求去重和按阅读器一次预热；预热只取令牌，不提交选区文本。

「加入笔记」会复用已完成的译文。当前阅读器有可编辑笔记时追加到末尾，保留已有文字、格式与图片；否则在当前文献下创建子笔记，独立附件则在同库创建独立笔记并提示。新笔记优先打开在 PDF 旁边，方便继续追加；不支持时打开正常笔记标签页。笔记保留原文、译文、来源以及已有的真实页码和位置。没有页码时明确标记，不推算。保存成功后显示结果；失败和未确认状态也会提示，重复点击同一完成任务不会重复写入。

## 回退

在 Zotero 插件管理器中停用本插件，再启用原版 Translate for Zotero，即可恢复旧版入口。原版设置保持不变。安装、配置迁移和回退步骤不修改 PDF 或论文书目信息；无需删除文库数据。停用本插件后，新分支配置仍可保留以供以后使用。上游已有的标题／摘要翻译、注释翻译等功能在被用户启用或操作时仍可能保存对应翻译内容，停用插件不会删除这些已经保存的内容。

## 开发与打包

```text
npm ci
npm run build
```

构建使用上游 `zotero-plugin-scaffold`，由 `addon/` 中的占位模板生成独立资源和本地化前缀，并在 `build/` 中生成 XPI。运行测试应使用模拟服务，避免向实际服务提交文献内容或消耗额度。构建完成不等于已安装或已通过 Zotero 界面验证。

启动调用顺序：初始化语言资源后调用 `await prepareReliableSetup()`，再初始化默认设置和注册入口。返回 `shouldActivate: false` 时不得注册 Reader 事件、快捷键、菜单、侧栏及其他可触发翻译的入口。返回的 `migrated` 仅表示本次调用是否完成迁移并复制过旧版用户设置，不包含配置名称或值。
